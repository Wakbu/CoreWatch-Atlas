# CoreWatch-Atlas Web 대시보드 MVP

완료일: 2026-07-28

Atlas Server가 기존 API와 Web 대시보드를 함께 제공한다. 별도 프런트 서버 없이 Server를 실행하고 루트 URL에 접속하면 Windows, Linux, macOS와 모바일 브라우저에서 사용할 수 있다.

## 구현 범위

- 접고 펼칠 수 있는 데스크톱 사이드바와 모바일 오버레이 메뉴
- 운영자 로그인 화면, 세션 확인과 로그아웃
- Viewer·Administrator 공통 조회 권한
- 등록된 모든 서버의 반응형 카드 그리드
- 온라인 상태, 운영체제, CPU·메모리·디스크, 마지막 수집과 활성 경고
- 전체·온라인·오프라인·경고 서버 요약
- 임계치 경고, 최근 수집 이벤트와 CPU 사용률 순위
- 서버 카드에서 상세 화면으로 이동
- 최근 24시간 CPU·메모리·디스크·네트워크 Canvas 차트
- 시스템 정보, 현재 경고와 Snapshot 이력 연결
- 서버 검색, 로딩·오류·빈 목록·검색 결과 없음 상태
- 키보드 탐색, 포커스, 상태 문구와 반응형 레이아웃

## 경고 기준

Web MVP의 경고는 최신 Snapshot에서 브라우저가 계산한다.

- 주의: CPU, 메모리 또는 디스크 사용률 70% 이상
- 긴급: 사용률 90% 이상 또는 Agent 오프라인

경고 규칙 영구 저장, 확인 처리와 외부 알림은 후속 운영 기능 범위다.

## 운영 경계

Agent 쓰기 API는 장비별 Bearer, 대시보드와 조회 API는 운영자 쿠키 인증을 사용한다. 아직 HTTPS와 운영용 쿠키 키 저장이 없으므로 loopback 또는 신뢰된 내부망에서만 실행한다.
