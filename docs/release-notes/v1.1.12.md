# v1.1.12

## 한국어

- GitHub REST API 공유 제한에 영향을 받지 않도록 공개 릴리스 리다이렉트를 우선 사용해 Server 자동 업데이트 탐색을 안정화했습니다.
- 서버 그룹 생성·구성 변경 후 최신 데이터를 즉시 다시 조회합니다.
- 그룹 구성 화면에서 `추가된 서버`와 `추가 가능한 서버`를 분리하고, 버튼 간격과 행 정렬을 개선했습니다.

## English

- Server update discovery now uses the public release redirect first, avoiding shared GitHub REST API rate limits.
- Server-group creation and membership changes immediately reload fresh data.
- Group membership now separates added servers from available servers, with improved action-button spacing and row alignment.
