# v1.1.9

## Linux Agent 자동 업데이트 / Linux Agent automatic updates

- 업데이트 상태 보고가 일시적으로 404여도 검증된 Agent 패키지 적용을 중단하지 않도록 수정했습니다.
- A transient 404 from update-status reporting no longer prevents a verified Agent package from being applied.

- 새 버전 Snapshot을 받으면 Server가 진행 중인 배포를 자동으로 성공 상태로 정합화합니다.
- When a new-version Snapshot arrives, Server automatically reconciles the active deployment to succeeded.

## 검증 / Verification

- 전체 자동화 테스트와 실제 Linux Agent 업데이트 검증을 수행했습니다.
- The full automated test suite and a real Linux Agent update verification were performed.
